# v0.5.0 Compare Before Release

**Baseline:** v0.4.4 Standalone Runtime Consolidation  
**Release:** v0.5.0 Mobile Immersion & Time Foundation  
**Final decision:** PASS

## Change summary

v0.5.0 adds the approved mobile interaction foundation and authoritative time system without removing any v0.4.4 capability.

Major additions:

- full-screen immersive mobile and portrait-tablet canvas;
- draggable, corner-snapping floating Control button;
- full-screen Tabs-and-Cards Control Center;
- Basic and Advanced complexity modes;
- shared Simulation Clock with minute-to-year presets;
- custom presets, exact date/time jump and deterministic reverse time;
- quality-tiered main asteroid belt;
- collision-aware labels;
- equivalent standalone and Canvas fallback behavior;
- hardened exclusive browser QA lifecycle.
