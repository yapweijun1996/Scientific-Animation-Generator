# v0.7.0 Compared with v0.6.0

## Unchanged scientific foundation

v0.7 preserves the v0.6 astronomy provider, Simulation Clock, Moon-phase definition, event engine, observer calculations, object facts, scientific classifications and verified-range disclosures.

No planet, moon or astronomical-provider accuracy claim was removed or weakened.

## New experience

v0.6 provides Explore and Learn. v0.7 adds Travel as a third experience using the same project time, renderer and snapshot contract.

## New domain modules

v0.7 adds:

- trajectory engine;
- mission state machine;
- Travel data contracts;
- WebGL spacecraft mission visual;
- Travel controller;
- standalone Travel controls and mission restoration;
- Travel-specific domain and browser gates.

## Snapshot changes

v0.7 snapshots may include:

- mission plan;
- active state;
- mission type and destination;
- camera mode and follow distance;
- simplified realism/fuel options;
- trajectory and key-event metadata.

A v0.6 snapshot without mission data remains valid and opens in Explore without creating Travel resources.

## Rendering changes

v0.7 adds a readable robotic probe and transfer trajectory only after a mission is planned or restored. Planet positions, Moon hierarchy, distance modes and v0.6 visual calculations are unchanged.

Canvas fallback receives the same mission plan/state and draws an equivalent trajectory and probe marker.

## Storage changes

Project writes are serialized. This prevents an older autosave from committing after a newer manual or camera-state save. IndexedDB open and transaction failure paths are bounded.

## Export changes

Standalone HTML and source ZIP exports include the current Travel plan, camera and mission state while preserving zero-CDN/offline behaviour.

## Deliberate exclusions

v0.7 does not add communication, power, thermal, radiation, instruments, random failures, launch vehicles, real propulsion mass or operational navigation.

## Regression requirements

Before v0.7 replaces v0.6, it must preserve:

- three-browser desktop/tablet/mobile responsive behaviour;
- WebGL primary renderer where available;
- Canvas fallback;
- v0.6 Learn and Observe interactions;
- offline mobile reload;
- direct-file standalone execution;
- HTML and ZIP export;
- empty runtime error arrays.

Targeted Travel gates meet their acceptance criteria. The consolidated regression matrix remains pending because of shared QA-host instability, so the stable URL remains v0.6.0.
