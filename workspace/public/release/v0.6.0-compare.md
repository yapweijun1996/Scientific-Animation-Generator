## Scientific architecture

### v0.5.0

- Unified simulation clock.
- Deterministic Worker and Canvas recomputation.
- Rounded fixed planetary constants.
- No event engine, observer service or structured scientific report.

### v0.6.0

- Astronomy provider boundary with installed provider metadata.
- Astronomical event engine.
- Observer-location service.
- Object-science catalogue.
- Scientific accuracy report with 13 checks and explicit classifications.
- Moon principal phases based on geocentric ecliptic longitude difference.
- True 3D elongation retained separately for physical display.

## Distance-model correction

The legacy Linear AU option in v0.5 placed bodies at linear AU distances but retained teaching-scale body sizes and a camera designed for compressed spacing. Field testing showed inner bodies apparently inside the Sun and outer planets outside the viewport.

v0.6.0 changes this presentation layer without changing calculated orbital state:

- Legacy scientific snapshots migrate to Real Distance.
- Linear AU orbit ordering is retained.
- Sun, planet and Moon sizes use overlap-safe bounds.
- Earth–Moon separation receives a dedicated safety envelope.
- Camera framing derives from the outermost aphelion and current aspect ratio.
- Focus Sun means complete system overview in non-learning modes.
- Locator labels support sub-pixel objects.
- WebGL and Canvas use the same rules.
