# Scientific Animation Generator v0.4.3

## Architecture Refactor

v0.4.3 is a maintenance and architecture release. It preserves the full v0.4.2 visual and export feature set while reducing hidden dependencies, duplicated simulation logic and Canvas fallback work.

## Main changes

- `moon-data.ts` is now data-only. Importing Moon constants no longer injects CSS, polls the DOM or patches editor text.
- A typed celestial catalog now defines the Sun, eight planets and Earth’s Moon for focus controls and object lookup.
- Kepler solving, orbital positions, body rotation, AU compression, body radius and Moon orbit calculations are centralized in one shared domain module.
- The simulation Worker, Three.js runtime and Canvas fallback now reuse that shared orbital math.
- The editor explicitly renders Moon in the Focus selector and uses centralized application/version constants.
- Canvas fallback caches all eight orbital paths and updates pixel density immediately when quality changes.
- Runtime scene updates no longer fabricate Worker messages after a visual spacing change.
- Three.js materials now carry explicit ownership markers to prevent overlapping disposal responsibilities.
- Dependency versions are pinned for repeatable builds.
- PWA install readiness now includes 192/512 scalable icons, iOS standalone metadata, Apple touch icon support and a cached `offline.html` fallback.

## Compatibility

- No change to Earth, Moon, Saturn rings or other planet visuals.
- No change to authoritative orbital constants or Moon tidal locking.
- Existing `.scienceproject` files remain compatible.
- WebGL, Canvas fallback, Low/Auto/High quality, offline PWA, zero-CDN standalone HTML and ZIP export remain supported.
- No new celestial bodies, binary Moon assets, CDN dependencies or external runtime requests were added.

## Validation

- TypeScript typecheck, production build, standalone export syntax and ZIP assertions passed.
- Shared domain tests passed for Kepler residuals, orbital period repetition, Moon period repetition, visual scaling and retrograde rotation.
- Chromium, Firefox and WebKit desktop/mobile checks passed without page errors, failed application assets or horizontal overflow.
- PWA source audit passed 19 checks with 0 warnings and 0 errors.
