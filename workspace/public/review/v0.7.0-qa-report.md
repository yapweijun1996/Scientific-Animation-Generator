## Defects found and fixed during QA

1. **Travel initialized during Explore startup**  
   Fixed with lazy mission planning and lazy spacecraft visual creation.

2. **Hidden Travel dashboard rebuilt every Worker tick**  
   Fixed with visibility-aware low-frequency rendering.

3. **Free Camera reverted to Follow after reload**  
   Root cause was stale concurrent autosave transactions and competing snapshot authorities. Fixed with serialized project saves and runtime mission-state authority.

4. **Paused mission time jump showed stale dashboard progress**  
   Fixed by updating runtime mission state before UI notification and adding a trailing dashboard refresh.

5. **IndexedDB could block startup indefinitely**  
   Added bounded open, blocked, error and abort handling with safe application fallback.

6. **Headless QA target instability**  
   Chromium QA uses `--disable-dev-shm-usage`, 1280×800 desktop coverage and explicit bounded polling. The final isolated matrix completed without target crashes or navigation timeouts.
