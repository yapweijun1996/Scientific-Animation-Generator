# Solar System Explorer v0.5.0 Release Notes

**Release:** Mobile Immersion & Time Foundation  
**Date:** 2026-07-30  
**Baseline:** v0.4.4 Standalone Runtime Consolidation

## Overview

v0.5.0 turns the existing Solar System scene into a mobile-first immersive explorer and establishes one authoritative Simulation Clock for the editor, Web Worker, Three.js renderer, Canvas fallback and standalone export.

The release preserves the v0.4.4 offline-first PWA, zero-CDN standalone HTML, source ZIP, planet textures, Earth–Moon hierarchy, Saturn ring stability, IndexedDB save/restore and shared generated-runtime architecture.

## Mobile immersion

- Mobile and portrait-tablet layouts now dedicate the full viewport to the simulation canvas when controls are closed.
- Permanent mobile toolbars, timelines and side panels were removed from the main scene.
- A single floating Control button opens a full-screen Control Center.
- The floating button supports dragging, safe-corner snapping and locally persisted placement.
- The Control Center uses Tabs and Cards for Time, View, Objects, Learn, Travel, Quality and Data controls.
- Basic and Advanced complexity modes are locally persisted.
- Safe-area insets, touch targets, reduced-motion handling and mobile overflow were improved.
- Celestial focus state is synchronised across scene selection, desktop controls, mobile controls and standalone runtime.

## Simulation Clock

- Added a shared `SimulationClock` domain using the epoch `2026-01-01T00:00:00.000Z`.
- Added minute, hour, day, week, month and year playback presets.
- Added custom local time presets.
- Added exact date and time input.
- Added fine playback-rate control.
- Advanced Mode supports signed playback and deterministic reverse time.
- Reverse time recomputes orbital state for the requested time rather than replaying rendered frames.
- Snapshot data now preserves playback state, signed rate, direction and complexity mode.
- Default speed was reduced from 32 days per second to 1 day per second.

## Scene improvements

- Added a deterministic main asteroid belt between Mars and Jupiter.
- Asteroid count and visual detail scale with Low, Auto and High quality modes.
- The Canvas fallback includes an equivalent asteroid-belt representation.
- Label placement now uses focus priority and collision reduction, improving inner-planet readability.
- Jupiter and Saturn retain the v0.4.4 polished materials, texture handling and stable Saturn ring hierarchy.

## Standalone and offline parity

- The generated standalone runtime includes the v0.5 Control Center and Simulation Clock controls.
- Direct-file standalone HTML remains network independent.
- Source ZIP continues to package the same standalone builder, project snapshot, textures, README and attribution.
- PWA cache advanced to `science-animator-v12-mobile-time`.
- Offline reload, mobile Control Center, Moon focus, reverse time and Canvas fallback were verified.

## QA lifecycle reliability

The browser QA harness was hardened to prevent intermittent release-gate failures:

- one exclusive suite lock prevents concurrent cleanup/build races;
- the embedded static server uses an operating-system-assigned port;
- server startup is awaited before browser navigation;
- open sockets are tracked and shutdown is awaited;
- standalone smoke HTML and browser artifacts are copied to a run-specific directory;
- only a fully passing matrix atomically replaces the official release evidence;
- failed runs preserve their own evidence instead of overwriting the last passing result;
- missing non-HTML assets return HTTP 404 instead of silently returning `index.html`.

## Compatibility

No new CDN, analytics, mandatory cloud API or external runtime request was added. The release preserves:

- Three.js primary rendering;
- interactive Canvas 2D fallback;
- all eight planets and Earth’s Moon;
- bundled real planet textures and attribution;
- stable Saturn rings;
- `.scienceproject` save/import;
- standalone HTML and ZIP export;
- PWA installation and offline reload;
- Chromium, Firefox and WebKit support.
