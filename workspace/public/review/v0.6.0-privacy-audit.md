# v0.6.0 Privacy and Data-Handling Audit

Status: **pass for application behavior; hosting-layer disclosure required and present**.

## Application data

The application processes simulation state, visual controls, focused objects, learning progress, saved project snapshots, observer locations and files explicitly exported by the user.

## Application behavior

- State and snapshots remain in browser-local storage/IndexedDB.
- Observer coordinates are used for local educational sky calculations.
- Application source contains no analytics, advertising, account system, third-party telemetry integration or automatic GPS request.
- The application does not upload observer locations or saved project content.
- Standalone HTML and ZIP exports contain no CDN, analytics or required network dependency.
- Users can clear data through browser site-data controls.

## Published hosting layer

Post-publication capture of the public `content.gmb01.xyz` share route observed a Cloudflare Insights beacon injected by the hosting platform. This script is not present in project source or standalone export. The hosting platform and infrastructure provider may process technical request and performance metadata under their own terms.

The privacy audit tool correctly warns that a disclosed third-party hosting service requires scope review. This warning is accepted because:

- the service is outside project source;
- its scope is documented in public `PRIVACY.md`;
- application observer coordinates and project snapshots are not sent to it;
- standalone and ZIP exports do not contain it.

## Result

The project privacy posture is acceptable for the v0.6.0 educational offline-first release. No application-level personal-data store, analytics workflow or third-party telemetry integration was found. Hosting-layer technical processing is disclosed rather than attributed to application code.
