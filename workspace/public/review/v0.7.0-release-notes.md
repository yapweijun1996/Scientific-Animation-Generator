# v0.7.0 Spacecraft Travel — Release Notes

Status: **release candidate; not yet published**

v0.7 adds a third experience to Solar System Explorer: **Travel Mode**. Users can plan and observe simplified robotic missions from Earth to each planet while the planets, spacecraft and mission dashboard remain synchronized to the same Simulation Clock.

## What is new

- Earth-origin destination catalogue covering all eight planets.
- Local Earth-orbit rehearsal.
- Fly-by and Orbiter mission types.
- Automatic Hohmann transfer planning.
- Launch-window wait, departure, arrival, duration, path distance and Delta-v information.
- Mission states and key-event timeline.
- Follow and Free spacecraft cameras.
- Near, Standard and Far follow distances.
- Optional simplified fuel realism and key-event auto-pause.
- WebGL spacecraft and trajectory rendering with Canvas 2D parity.
- Travel state in project snapshots, standalone HTML and source ZIP exports.

## Scientific honesty

Only the installed Hohmann model is selectable. Direct transfer and Gravity Assist are displayed as unavailable with a scientific reason. v0.7 does not fabricate unsupported routes.

The Travel model is classified as **Educational Accuracy**. It is not a launch-vehicle, navigation or operational mission-design system.

## Reliability improvements

- Travel initializes only when opened, planned or restored.
- IndexedDB access is bounded and cannot hold the application in startup indefinitely.
- Project saves are serialized to prevent older autosaves from replacing newer mission/camera state.
- Runtime mission state is saved as the authoritative Travel state.
- Mission dashboard updates include a trailing refresh for paused deterministic jumps.
- WebGL and Canvas update mission state before publishing clock changes to the UI.

## Compatibility retained

v0.7 preserves v0.6:

- Explore and Learn modes;
- Moon phases, eclipse geometry, seasons and observer tools;
- Learning Scale, Real Distance and Real Scale;
- reverse time and exact date/time jumps;
- offline PWA behaviour;
- standalone HTML and ZIP export;
- Chromium/WebKit WebGL and Canvas fallback architecture;
- local-only project and observer data handling.

## Deliberate non-goals

The following remain outside v0.7 and are reserved for a future spacecraft-systems phase:

- communication delay and link budgets;
- electrical power and battery systems;
- thermal control;
- radiation environment;
- scientific instrument dashboards;
- launch vehicles, staging and atmospheric ascent;
- random failures or damage systems.

## Candidate status

Targeted Travel browser, Canvas and standalone gates pass. Lint, typecheck, production build, domain regression, export smoke and PWA audit pass. The stable v0.6 URL will not be overwritten until one clean consolidated browser matrix completes on the shared QA host.
