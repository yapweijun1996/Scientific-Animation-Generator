# Scientific Animation Generator v0.4.4

## Standalone Runtime Consolidation

Released: 2026-07-29

v0.4.4 replaces the large manually duplicated standalone Solar System runtime with a generated bundle built from the same shared modules used by the main editor. The standalone HTML remains a single offline file with zero CDN or external runtime dependencies.

## Architecture changes

- Added dedicated standalone entry, bootstrap, UI and type modules under `src/standalone/`.
- Added a deterministic build step that compiles the shared runtime into `src/standalone/generated-runtime.ts`.
- Injected the simulation Worker factory and planet texture resolver into the shared `SolarSystemRuntime`.
- Reused the authoritative celestial catalog, orbital math, parameter readers, planet/Moon definitions, Three.js runtime, Canvas fallback and texture catalog.
- Reduced `src/export/standalone-export.ts` from a duplicated runtime implementation to approximately 3.2 KB of export orchestration.
- Kept ZIP export on the same standalone HTML builder, avoiding a second export implementation.
- Advanced the PWA cache to `science-animator-v11-standalone-runtime`.

## Release packaging fix

The first published candidate exposed a source-workspace packaging gap: the runtime requested Earth texture URLs that were present in the older project store but absent from the newly built `dist`. The release was not closed in that state.

The final release now:

- stores all 12 planet texture files and the attribution manifest under `public/assets/planets/`;
- copies them into every production build;
- validates their exact presence and byte sizes during `npm run build`;
- fails browser QA on any HTTP 4xx or 5xx response;
- passed a second full browser/export/offline test after the fix.

## Preserved behavior

- Sun, all eight planets and Earth’s Moon.
- Moon orbit, tidal locking, cratered procedural surface, phases, labels and focus.
- Earth layers, real planet maps, Saturn’s stable ring hierarchy and planet polish.
- Low, Auto and High quality modes.
- Playback, reset, timeline, focus, Undo/Redo, IndexedDB autosave and project import/export.
- WebGL primary renderer and interactive Canvas 2D fallback.
- iPad-first desktop, tablet and mobile layouts.
- Offline PWA, direct local-file standalone HTML and source ZIP export.
