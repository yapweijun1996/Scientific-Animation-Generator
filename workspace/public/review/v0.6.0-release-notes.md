# Scientific Animation Generator v0.6.0

## Scientific Learning & Observation

v0.6.0 turns Solar System Explorer from a visual simulator into a structured educational observation environment while preserving the v0.5 mobile-first runtime, offline PWA, standalone HTML export, ZIP export, WebGL renderer and Canvas fallback.

## Added

- Explore and Learn experience modes.
- Basic and Advanced scientific information layers.
- Guided modules for Moon phases, eclipse geometry and seasons.
- Astronomical event catalogue with event-time jumping.
- Object information for the Sun, eight planets and Earth’s Moon.
- Sources & Accuracy panel with provider identity, version, verified range, expected error and known limitations.
- Observer locations, altitude/azimuth, local time, horizon visibility and multi-location comparison.
- Learning Scale, Real Distance and Real Scale presentation modes.
- Scientific accuracy report download.
- Deterministic QA stepping for forward and reverse time.
- Visual diagnostics that verify camera framing and visible-body overlap boundaries.
- Privacy and proprietary-code licence notices.

## Corrected after field testing

- Linear AU / Real Distance no longer combines linear orbit positions with oversized teaching bodies.
- Mercury remains outside the visible Sun envelope.
- Earth and Moon visible-body envelopes remain separated.
- Focus Sun in Real Distance and Real Scale now produces a complete Solar System overview instead of a solar close-up.
- Outer planets are automatically framed within the camera view.
- The same safe distance and size rules are used by WebGL and Canvas.
- v0.5 snapshots using the former scientific distance option migrate to Real Distance.

## Moon phase definition

Principal Moon phases are now solved from the geocentric ecliptic longitude difference between the Moon and Sun:

- New Moon: 0°
- First Quarter: 90°
- Full Moon: 180°
- Last Quarter: 270°

True three-dimensional elongation remains available as a displayed physical measurement. It can differ slightly from exactly 0° or 180° because the Moon can have non-zero ecliptic latitude.

## Scientific classification

The application distinguishes:

- **Calculated** — deterministic output produced by the installed model.
- **Dataset verified** — externally checked against an identified reference dataset. No v0.6 result claims this classification because no external ephemeris dataset is bundled.
- **Educational approximation** — scientifically motivated output from the simplified installed provider.
- **Visual enhancement** — size, spacing, lighting or visibility changes that do not alter calculated state.
- **Outside verified range** — output requested outside the provider’s declared 1900–2100 release range.

Eclipse entries are educational geometry candidates. They are not authoritative local eclipse-contact predictions.

## Known limitations

- Planetary positions use rounded fixed orbital elements and a deterministic Kepler solver.
- Perturbations, precession, nutation, aberration and light-time correction are not included.
- The Moon uses a simplified fixed-inclination orbit and circular mean distance.
- Real Distance correctly preserves linear AU ordering, but inner objects naturally cluster in a complete-system view. Focus and locator labels are used for readability.
- Real Scale may make bodies too small to see without locator labels.
- Observer and eclipse output is educational and must not be used for navigation, safety decisions or authoritative civil predictions.
