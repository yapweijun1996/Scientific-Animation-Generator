# v0.5.0 Mobile Immersion & Time Foundation

## Durable implementation summary

Solar System Explorer v0.5.0 establishes the mobile interaction and time foundation for future Learn and Travel modes.

### Authoritative time

- `src/core/simulation-clock.ts` is the shared time conversion and preset domain.
- Simulation epoch: `2026-01-01T00:00:00.000Z`.
- Playback rate is signed days per real second.
- Negative playback recomputes orbital state from simulation time; it is not frame reversal.
- Editor, Worker, Three.js runtime, Canvas fallback and standalone runtime share the same time semantics.

### Mobile UI contract

- On mobile and portrait tablet, the scene fills the viewport while controls are closed.
- One floating Control button is the persistent mobile control.
- The button snaps to safe corners and persists its position locally.
- The full-screen Control Center uses Tabs and Cards.
- Opening or closing controls must preserve camera, focus and simulation state.

### Rendering additions

- The main asteroid belt is deterministic and quality tiered.
- Performance reduction changes asteroid count and visual detail before scientific state.
- Label collision handling prioritises the focused object and reduces inner-system overlap.

### Export compatibility

- Standalone HTML is generated from the shared runtime and contains the v0.5 mobile/time UI.
- ZIP uses the same standalone builder.
- PWA, direct file, Canvas fallback and offline behaviour remain mandatory parity gates.

### QA lifecycle rule

Browser QA must run through `qa/run-test-suite.js`:

1. acquire the exclusive QA lock;
2. build production output;
3. generate isolated standalone/domain bundles;
4. generate and validate the standalone smoke HTML;
5. start the embedded server on an OS-assigned port;
6. copy the standalone smoke file into a run-scoped directory;
7. execute the Chromium/Firefox/WebKit matrix;
8. atomically promote evidence only after the complete matrix passes;
9. await HTTP server and socket shutdown;
10. release the suite lock.

Do not revert to a fixed port or shared temporary evidence directory. Concurrent suites must be rejected rather than allowed to delete each other’s generated files.
