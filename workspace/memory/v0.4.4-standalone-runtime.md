# v0.4.4 Standalone Runtime Consolidation Memory

## Decision

The standalone HTML export must not maintain a manually duplicated Solar System runtime. It is generated from the same shared runtime and domain modules used by the editor.

## Architecture

- `src/standalone/standalone-entry.ts` is the standalone build entry and provides the inline Worker factory.
- `src/standalone/standalone-bootstrap.ts` owns standalone startup, snapshot restoration, controls, resize handling and the public runtime API.
- `src/standalone/standalone-ui.ts` owns the standalone shell and responsive control UI.
- `src/standalone/generated-runtime.ts` is generated by `scripts/build-standalone-runtime.js`; do not edit it manually.
- `SolarSystemRuntime` accepts explicit Worker and planet texture-source dependencies so the editor and standalone bundle use the same runtime.
- `src/export/standalone-export.ts` only validates, embeds config/textures and downloads the generated bundle.
- `src/export/zip-export.ts` calls the same standalone HTML builder.

## Asset ownership rule

Planet texture binaries are source-controlled build inputs under `public/assets/planets/high/`; the attribution manifest is under `public/assets/planets/attribution-manifest.json`.

Do not rely on files that happen to exist in persistent project storage or a prior published release. `npm run build` must fail when any required source or `dist` texture is absent or has an unexpected byte size. Browser QA must also fail on any HTTP response with status 400 or higher.

This rule was added after the first v0.4.4 published candidate exposed 404 responses for Earth day, night and cloud maps. The issue was fixed before final release and the full test matrix was rerun.

## Maintenance rule

When shared Solar System code changes, run `npm run generate:standalone`, typecheck, production build and the full test suite. The generated bundle version must match `APP_VERSION`. Never reintroduce celestial data, orbital formulas, rendering code or fallback logic directly into `standalone-export.ts`.

## Required release gates

- zero external script/CDN references;
- exactly one inline script in exported HTML;
- all planet texture files present in source and production output;
- no browser HTTP 4xx or 5xx responses;
- direct `file://` operation;
- Worker, WebGL and Canvas fallback parity;
- standalone and ZIP snapshot/version validation;
- Chromium, Firefox and WebKit checks;
- desktop, tablet and mobile checks;
- real export download verification;
- offline cached reload;
- accessibility audit;
- post-publish HTTPS inspection.

## Verified v0.4.4 baseline

- Generated runtime: 629,815 bytes.
- Standalone export orchestration: approximately 3,213 bytes.
- Final standalone HTML with embedded maps: 7,901,208 bytes.
- Final source ZIP: 5,521,957 bytes.
- Browser matrix, direct file, offline, fallback, exports and HTTP status gates passed on 2026-07-29.
- Rollback backup: `backup_2206707b-dc7_ms4glqok`.
